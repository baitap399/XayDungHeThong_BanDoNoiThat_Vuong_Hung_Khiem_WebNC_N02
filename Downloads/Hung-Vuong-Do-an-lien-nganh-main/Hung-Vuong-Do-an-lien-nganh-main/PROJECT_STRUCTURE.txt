logic nghiệp vụ cơ bản

1. người dùng
   đăng ký → đăng nhập → xác thực jwt → kiểm tra quyền truy cập.

2. sản phẩm
   frontend → products api → products service → database → trả dữ liệu về frontend.

3. giỏ hàng
   người dùng chọn sản phẩm → thêm vào giỏ hàng → cập nhật số lượng → xóa sản phẩm.

4. đặt hàng
   người dùng xác nhận giỏ hàng → gửi thông tin đặt hàng → backend kiểm tra dữ liệu → tạo đơn hàng → lưu database.

5. quản trị
   admin đăng nhập → xác thực quyền → quản lý sản phẩm, người dùng, đơn hàng, doanh thu và tin nhắn.

6. giao tiếp hệ thống
   react frontend → rest api → nestjs backend → typeorm → mysql/aiven → trả kết quả về frontend.
